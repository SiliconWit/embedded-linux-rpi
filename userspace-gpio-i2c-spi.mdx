On a microcontroller you read a pin by reading a register. On Linux an ordinary program is not allowed to touch a register, and many people conclude that every button and sensor needs a kernel driver, which is slow to write and can stop the whole board when it has a bug. Most of the time that is wrong. The kernel already offers pins and buses to ordinary programs as device files under /dev. In this lesson you use three of them (GPIO, I2C and SPI) and build a doorbell monitor: a push button produces a GPIO event, and the program switches an LED and logs temperature, humidity and pressure from a BME280 sensor. You write no kernel code. #LinuxGPIO #Libgpiod #UserspaceDrivers

## Userspace vs Kernel-Space Hardware Access

<InArticleAd />


Code that operates a peripheral can live in an ordinary program, or inside the kernel as a driver. The choice decides how fast the code reacts, and what happens when it has a bug.

| Aspect | Userspace Access | Kernel-Space Access |
|--------|-----------------|-------------------|
| Interface | Character devices (`/dev/i2c-1`, `/dev/spidev0.0`, `/dev/gpiochipN`) | Kernel modules and drivers |
| Latency | Higher (syscall overhead, scheduling) | Lower (direct register access, interrupt context) |
| Safety | Crash does not take down the system | Bug can panic the kernel |
| Debugging | Standard tools (gdb, printf, strace) | printk, ftrace, kgdb |
| When to use | Prototypes, sensors, slow peripherals | Strict timing, fast protocols, hardware shared by many programs |

For a sensor that is read a few times per second, userspace is the right place.

The kernel still owns the pins and the buses, and its bus drivers move every bit. Your program decides what to send, and asks through a device file. It is like a shop with a counter: customers (programs) ask at a window, and only the clerk (the kernel) goes into the store room where the registers are. A customer who drops something affects only himself, but every request costs the clerk a trip, which is why userspace is slower for strict timing. The path of each request:

```text
  Three device files, one kernel
  ──────────────────────────────────────────
  Your C program
    │          │           │
    ▼          ▼           ▼
  libgpiod  /dev/i2c-1  /dev/spidev0.0
  (GPIO)    (I2C)       (SPI)
    │          │           │
    ▼          ▼           ▼
  ┌──────────────────────────────────────┐
  │             Linux kernel             │
  │  gpiochip driver   i2c-bcm   spi-bcm │
  └──────────────────────────────────────┘
    │          │           │
    ▼          ▼           ▼
  GPIO pins   SDA/SCL    MOSI/MISO/CLK
```

The doorbell monitor has no loop that keeps reading the pin. It sleeps in `gpiod_line_event_wait()`, and the kernel wakes it when the button produces an edge:

```text
  One button press, from pin to log line
  ──────────────────────────────────────────
  Button ──► GPIO17 (pull-up, press = low)
                │
                ▼
  gpiod_line_event_wait()  ◄── sleeps here
                │
                │ falling edge
                ▼
  gpiod_line_event_read()
                │
                ├──► Toggle LED (GPIO27)
                ├──► Read BME280 over I2C
                └──► Log: "23.5C, 65%, 1013hPa"
```

## GPIO with libgpiod

<InArticleAd />


### Why sysfs GPIO is Deprecated

The old way to control GPIO from userspace was through `/sys/class/gpio/`:

```bash
# DO NOT USE - deprecated interface
echo 27 > /sys/class/gpio/export
echo out > /sys/class/gpio/gpio27/direction
echo 1 > /sys/class/gpio/gpio27/value
```

This interface has four problems:

- A pin has no owner. Any process can change a pin that another process is using.
- A pin stays exported after the program that exported it has crashed.
- Several pins cannot be changed at the same moment.
- There is no clean way to wait for an edge.

The sysfs GPIO interface was formally deprecated in Linux 4.8, and many modern kernels are built without it.

The replacement is the **GPIO character device**: one file per GPIO controller, `/dev/gpiochip0`, `/dev/gpiochip1` and so on. A program requests the lines (pins) it needs. A requested line belongs to that program alone, and the kernel releases it when the program ends, even after a crash. The **libgpiod** library gives you command-line tools and C functions for this interface.

The commands and C code in this lesson use libgpiod version 1 (1.6.x, the version packaged by Raspberry Pi OS Bookworm and Ubuntu 22.04). Check yours with `gpiodetect --version`.

libgpiod 2.x changed both the tools and the library:

- The tools take the chip as an option, for example `gpioset -c gpiochip0 27=1`, `gpioget -c gpiochip0 17` and `gpiomon -c gpiochip0 -e falling 17`.
- `gpioset` keeps running to hold the line and does not exit.
- The C functions were replaced (`gpiod_chip_request_lines()` takes the place of `gpiod_chip_get_line()` and the `gpiod_line_request_*()` calls), so the programs below do not compile against the version 2 header.



```bash

```

### Blink an LED with the libgpiod C API

Every libgpiod program has the same four steps: open the chip, get the line, request the line (as output or input, with a consumer name), and release it at the end. Create a file called `blink.c`:

```c title="blink.c"
#include <gpiod.h>
#include <stdio.h>
#include <unistd.h>

#define GPIO_CHIP "/dev/gpiochip0"
#define LED_LINE  27

int main(void)
{
    struct gpiod_chip *chip;
    struct gpiod_line *led;
    int ret;

    chip = gpiod_chip_open(GPIO_CHIP);
    if (!chip) {
        perror("gpiod_chip_open");
        return 1;
    }

    led = gpiod_chip_get_line(chip, LED_LINE);
    if (!led) {
        perror("gpiod_chip_get_line");
        gpiod_chip_close(chip);
        return 1;
    }

    ret = gpiod_line_request_output(led, "blink-app", 0);
    if (ret < 0) {
        perror("gpiod_line_request_output");
        gpiod_chip_close(chip);
        return 1;
    }

    printf("Blinking LED on GPIO%d. Press Ctrl+C to stop.\n", LED_LINE);

    for (int i = 0; i < 20; i++) {
        gpiod_line_set_value(led, 1);
        usleep(500000);  /* 500 ms on */
        gpiod_line_set_value(led, 0);
        usleep(500000);  /* 500 ms off */
    }

    gpiod_line_release(led);
    gpiod_chip_close(chip);

    return 0;
}
```

**Compile and run:**

```bash
gcc -o blink blink.c -lgpiod
sudo ./blink
```

The LED blinks 20 times, 500 ms on and 500 ms off (a 1 s period). While the program runs, `gpioinfo` shows GPIO27 with the consumer `"blink-app"`, and no other program can request that line.

## Edge Detection and Events

<InArticleAd />


A loop that reads an input again and again (polling) keeps the processor busy for nothing, and it misses a pulse that is shorter than the time between two reads. With events, your program asks the kernel to watch the line and then sleeps. The kernel uses the pin's hardware interrupt, records the time of each edge, and wakes your program. A falling edge is a change from high to low, a rising edge from low to high.

Look at three calls: `gpiod_line_request()` asks for falling-edge events, `gpiod_line_event_wait()` sleeps until an event or the timeout, and `gpiod_line_event_read()` fetches the event with its timestamp.

```c title="button_event.c"
#include <gpiod.h>
#include <stdio.h>
#include <time.h>

#define GPIO_CHIP   "/dev/gpiochip0"
#define BUTTON_LINE 17

int main(void)
{
    struct gpiod_chip *chip;
    struct gpiod_line *button;
    struct gpiod_line_event event;
    struct timespec timeout = { .tv_sec = 10, .tv_nsec = 0 };
    int ret;

    chip = gpiod_chip_open(GPIO_CHIP);
    if (!chip) {
        perror("gpiod_chip_open");
        return 1;
    }

    button = gpiod_chip_get_line(chip, BUTTON_LINE);
    if (!button) {
        perror("gpiod_chip_get_line");
        gpiod_chip_close(chip);
        return 1;
    }

    /* Request falling-edge events with internal pull-up bias */
    struct gpiod_line_request_config config = {
        .consumer = "button-monitor",
        .request_type = GPIOD_LINE_REQUEST_EVENT_FALLING_EDGE,
        .flags = GPIOD_LINE_REQUEST_FLAG_BIAS_PULL_UP,
    };

    ret = gpiod_line_request(button, &config, 0);
    if (ret < 0) {
        perror("gpiod_line_request");
        gpiod_chip_close(chip);
        return 1;
    }

    printf("Waiting for button press on GPIO%d (10s timeout)...\n", BUTTON_LINE);
    printf("%-6s  %-20s  %s\n", "Event", "Timestamp (s.ns)", "Type");

    int count = 0;
    while (1) {
        ret = gpiod_line_event_wait(button, &timeout);
        if (ret < 0) {
            perror("gpiod_line_event_wait");
            break;
        }
        if (ret == 0) {
            printf("Timeout, no event detected.\n");
            break;
        }

        ret = gpiod_line_event_read(button, &event);
        if (ret < 0) {
            perror("gpiod_line_event_read");
            break;
        }

        count++;
        printf("%-6d  %ld.%09ld  %s\n",
               count,
               event.ts.tv_sec,
               event.ts.tv_nsec,
               (event.event_type == GPIOD_LINE_EVENT_FALLING_EDGE)
                   ? "FALLING" : "RISING");
    }

    gpiod_line_release(button);
    gpiod_chip_close(chip);

    printf("Total events: %d\n", count);
    return 0;
}
```

**Compile and run:**

```bash
gcc -o button_event button_event.c -lgpiod
sudo ./button_event
```

What to notice:

- `GPIOD_LINE_REQUEST_FLAG_BIAS_PULL_UP` switches on the pull-up resistor inside the chip, which holds GPIO17 high while the button is open. The button only has to connect GPIO17 to GND, and no external resistor is needed.
- The program uses almost no CPU while it sleeps in `gpiod_line_event_wait()`.
- The kernel takes the timestamp at the moment of the edge, so it does not depend on how late your program wakes.
- The 10-second timeout ends the program if nobody presses the button.

## I2C from Userspace

<InArticleAd />


The `i2c-dev` kernel module shows each I2C bus as a device file (`/dev/i2c-0`, `/dev/i2c-1` and so on). Your program calls `open()` on the bus, one `ioctl()` to choose the device address, then `write()` and `read()` to move bytes. The kernel produces the start condition, the address byte and the acknowledge bits.

### Enable i2c-dev

Load the module:

```bash
sudo modprobe i2c-dev
ls /dev/i2c-*
```

You should see `/dev/i2c-1` (the I2C bus exposed on the GPIO header).

### Scan the Bus

```bash
i2cdetect -y 1
```

If your BME280 is wired correctly, you see `76` (or `77`) in the output. If the kernel's bmp280 driver has already taken the device, because your [device tree overlay](/education/embedded-linux-rpi/device-trees-hardware-description/) is still loaded, you see `UU`.

<Card title="Important" icon="warning">
A device has one owner. If a kernel driver (such as the bmp280 driver started by your device tree overlay) holds the sensor, your program cannot also use it through `i2c-dev`: the kernel reports the address as busy. To read the sensor from your own program, remove the `dtoverlay=` line of the overlay and reboot, or unload the driver: `sudo rmmod bmp280_i2c`. In a product, choose one of the two ways.
</Card>

### BME280 I2C Communication in C

With the kernel driver, you read finished values from files. Here your program does the driver's work itself.

The BME280 holds its settings and results in registers, numbered bytes inside the chip. To read one, you write the register number, then read back data bytes. The chip ID register (0xD0) returns 0x60 for a BME280 (or 0x58 for a BMP280).

The program is long, but it has four parts:

1. Two helpers that write and read registers.
2. `read_calibration()`, which reads the correction numbers that the factory stored in the chip.
3. Three `compensate_*()` functions from the Bosch datasheet, which turn raw readings into degrees, hPa and percent. You do not need to follow their arithmetic.
4. `main()`, which opens the bus, checks the chip ID, configures the sensor and reads it once.

```c title="bme280_i2c.c"
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/ioctl.h>
#include <linux/i2c-dev.h>

#define I2C_BUS     "/dev/i2c-1"
#define BME280_ADDR 0x76

/* BME280 register addresses */
#define REG_CHIP_ID     0xD0
#define REG_CTRL_HUM    0xF2
#define REG_CTRL_MEAS   0xF4
#define REG_CONFIG       0xF5
#define REG_PRESS_MSB   0xF7
#define REG_CALIB_T1    0x88
#define REG_CALIB_H1    0xA1
#define REG_CALIB_H2    0xE1

static int i2c_fd;

static int i2c_write_byte(uint8_t reg, uint8_t value)
{
    uint8_t buf[2] = { reg, value };
    if (write(i2c_fd, buf, 2) != 2) {
        perror("i2c write");
        return -1;
    }
    return 0;
}

static int i2c_read_bytes(uint8_t reg, uint8_t *buf, int len)
{
    if (write(i2c_fd, &reg, 1) != 1) {
        perror("i2c write register address");
        return -1;
    }
    if (read(i2c_fd, buf, len) != len) {
        perror("i2c read");
        return -1;
    }
    return 0;
}

/* Calibration data structure */
struct bme280_calib {
    uint16_t dig_T1;
    int16_t  dig_T2;
    int16_t  dig_T3;
    uint16_t dig_P1;
    int16_t  dig_P2;
    int16_t  dig_P3;
    int16_t  dig_P4;
    int16_t  dig_P5;
    int16_t  dig_P6;
    int16_t  dig_P7;
    int16_t  dig_P8;
    int16_t  dig_P9;
    uint8_t  dig_H1;
    int16_t  dig_H2;
    uint8_t  dig_H3;
    int16_t  dig_H4;
    int16_t  dig_H5;
    int8_t   dig_H6;
};

static struct bme280_calib calib;
static int32_t t_fine;  /* shared between temperature and pressure compensation */

static int read_calibration(void)
{
    uint8_t buf[26];
    uint8_t hbuf[7];

    /* Read temperature and pressure calibration (0x88..0xA1) */
    if (i2c_read_bytes(REG_CALIB_T1, buf, 26) < 0)
        return -1;

    calib.dig_T1 = (uint16_t)(buf[1] << 8 | buf[0]);
    calib.dig_T2 = (int16_t)(buf[3] << 8 | buf[2]);
    calib.dig_T3 = (int16_t)(buf[5] << 8 | buf[4]);
    calib.dig_P1 = (uint16_t)(buf[7] << 8 | buf[6]);
    calib.dig_P2 = (int16_t)(buf[9] << 8 | buf[8]);
    calib.dig_P3 = (int16_t)(buf[11] << 8 | buf[10]);
    calib.dig_P4 = (int16_t)(buf[13] << 8 | buf[12]);
    calib.dig_P5 = (int16_t)(buf[15] << 8 | buf[14]);
    calib.dig_P6 = (int16_t)(buf[17] << 8 | buf[16]);
    calib.dig_P7 = (int16_t)(buf[19] << 8 | buf[18]);
    calib.dig_P8 = (int16_t)(buf[21] << 8 | buf[20]);
    calib.dig_P9 = (int16_t)(buf[23] << 8 | buf[22]);

    /* Read H1 calibration (0xA1) */
    if (i2c_read_bytes(REG_CALIB_H1, &calib.dig_H1, 1) < 0)
        return -1;

    /* Read H2..H6 calibration (0xE1..0xE7) */
    if (i2c_read_bytes(REG_CALIB_H2, hbuf, 7) < 0)
        return -1;

    calib.dig_H2 = (int16_t)(hbuf[1] << 8 | hbuf[0]);
    calib.dig_H3 = hbuf[2];
    calib.dig_H4 = (int16_t)((hbuf[3] << 4) | (hbuf[4] & 0x0F));
    calib.dig_H5 = (int16_t)((hbuf[5] << 4) | (hbuf[4] >> 4));
    calib.dig_H6 = (int8_t)hbuf[6];

    return 0;
}

static double compensate_temperature(int32_t adc_T)
{
    int32_t var1, var2;
    var1 = ((((adc_T >> 3) - ((int32_t)calib.dig_T1 << 1)))
            * ((int32_t)calib.dig_T2)) >> 11;
    var2 = (((((adc_T >> 4) - ((int32_t)calib.dig_T1))
            * ((adc_T >> 4) - ((int32_t)calib.dig_T1))) >> 12)
            * ((int32_t)calib.dig_T3)) >> 14;
    t_fine = var1 + var2;
    return (t_fine * 5 + 128) / 256 / 100.0;
}

static double compensate_pressure(int32_t adc_P)
{
    int64_t var1, var2, p;
    var1 = ((int64_t)t_fine) - 128000;
    var2 = var1 * var1 * (int64_t)calib.dig_P6;
    var2 = var2 + ((var1 * (int64_t)calib.dig_P5) << 17);
    var2 = var2 + (((int64_t)calib.dig_P4) << 35);
    var1 = ((var1 * var1 * (int64_t)calib.dig_P3) >> 8)
         + ((var1 * (int64_t)calib.dig_P2) << 12);
    var1 = (((((int64_t)1) << 47) + var1)) * ((int64_t)calib.dig_P1) >> 33;
    if (var1 == 0)
        return 0.0;
    p = 1048576 - adc_P;
    p = (((p << 31) - var2) * 3125) / var1;
    var1 = (((int64_t)calib.dig_P9) * (p >> 13) * (p >> 13)) >> 25;
    var2 = (((int64_t)calib.dig_P8) * p) >> 19;
    p = ((p + var1 + var2) >> 8) + (((int64_t)calib.dig_P7) << 4);
    return (double)p / 256.0 / 100.0;  /* hPa */
}

static double compensate_humidity(int32_t adc_H)
{
    int32_t v;
    v = t_fine - 76800;
    v = (((((adc_H << 14) - (((int32_t)calib.dig_H4) << 20)
          - (((int32_t)calib.dig_H5) * v)) + 16384) >> 15)
        * (((((((v * ((int32_t)calib.dig_H6)) >> 10)
            * (((v * ((int32_t)calib.dig_H3)) >> 11) + 32768)) >> 10)
            + 2097152) * ((int32_t)calib.dig_H2) + 8192) >> 14));
    v = v - (((((v >> 15) * (v >> 15)) >> 7) * ((int32_t)calib.dig_H1)) >> 4);
    v = (v < 0) ? 0 : v;
    v = (v > 419430400) ? 419430400 : v;
    return (double)(v >> 12) / 1024.0;
}

int main(void)
{
    uint8_t chip_id;
    uint8_t data[8];
    int32_t adc_T, adc_P, adc_H;

    /* Open I2C bus */
    i2c_fd = open(I2C_BUS, O_RDWR);
    if (i2c_fd < 0) {
        perror("open i2c bus");
        return 1;
    }

    /* Set slave address */
    if (ioctl(i2c_fd, I2C_SLAVE, BME280_ADDR) < 0) {
        perror("ioctl I2C_SLAVE");
        close(i2c_fd);
        return 1;
    }

    /* Read and verify chip ID */
    if (i2c_read_bytes(REG_CHIP_ID, &chip_id, 1) < 0) {
        close(i2c_fd);
        return 1;
    }
    printf("Chip ID: 0x%02X", chip_id);
    if (chip_id == 0x60)
        printf(" (BME280 confirmed)\n");
    else if (chip_id == 0x58)
        printf(" (BMP280, no humidity)\n");
    else {
        printf(" (unexpected, check wiring)\n");
        close(i2c_fd);
        return 1;
    }

    /* Read calibration data */
    if (read_calibration() < 0) {
        close(i2c_fd);
        return 1;
    }

    /* Configure: humidity oversampling x1 */
    i2c_write_byte(REG_CTRL_HUM, 0x01);

    /* Configure: standby 1000ms, filter off (written while the sensor is
       still in sleep mode; writes to config may be ignored in normal mode) */
    i2c_write_byte(REG_CONFIG, 0xA0);

    /* Configure: temp oversampling x1, pressure oversampling x1, normal mode */
    i2c_write_byte(REG_CTRL_MEAS, 0x27);

    /* Wait for first measurement */
    usleep(50000);

    /* Read raw data (pressure[0:2], temperature[3:5], humidity[6:7]) */
    if (i2c_read_bytes(REG_PRESS_MSB, data, 8) < 0) {
        close(i2c_fd);
        return 1;
    }

    adc_P = ((int32_t)data[0] << 12) | ((int32_t)data[1] << 4) | (data[2] >> 4);
    adc_T = ((int32_t)data[3] << 12) | ((int32_t)data[4] << 4) | (data[5] >> 4);
    adc_H = ((int32_t)data[6] << 8)  | (int32_t)data[7];

    /* Compensate (temperature must be first, it sets t_fine) */
    double temp = compensate_temperature(adc_T);
    double pres = compensate_pressure(adc_P);
    double humi = compensate_humidity(adc_H);

    printf("Temperature: %.2f C\n", temp);
    printf("Pressure:    %.2f hPa\n", pres);
    printf("Humidity:    %.2f %%RH\n", humi);

    close(i2c_fd);
    return 0;
}
```

**Compile and run:**

```bash

```

```

Humidity:    45.30 %RH
```

The compensation formulas are from the Bosch BME280 datasheet (section 4.2.3). The temperature must be computed first, because the pressure and humidity formulas use its intermediate result `t_fine`.

## SPI from Userspace

<InArticleAd />


SPI has no device addresses: each device has its own chip select line. And the bus sends and receives at the same time: for every bit that goes out on MOSI, one bit comes in on MISO. The `spidev` kernel module shows each chip select as a device file (`/dev/spidev0.0`, `/dev/spidev0.1` and so on). The first number is the bus and the second is the chip select line. One `ioctl()` call does a complete transfer in both directions.

### Enable SPI

Add the following to `/boot/config.txt`:

```ini
dtparam=spi=on
```

Reboot, then verify:

```bash
ls /dev/spidev*
```

You should see `/dev/spidev0.0` and `/dev/spidev0.1`.

### SPI Loopback Test

For a loopback test, connect MOSI (GPIO10) to MISO (GPIO9) with a jumper wire. What you send on MOSI then comes back on MISO.

The program sets the SPI mode (the clock polarity and phase), the bits per word and the clock speed. Then it fills a `struct spi_ioc_transfer` with a send buffer and a receive buffer of the same length, and runs the transfer.

```c title="spi_loopback.c"
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <string.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/ioctl.h>
#include <linux/spi/spidev.h>

#define SPI_DEVICE  "/dev/spidev0.0"
#define SPI_SPEED   500000   /* 500 kHz */
#define SPI_BITS    8
#define SPI_MODE    SPI_MODE_0

int main(void)
{
    int fd;
    uint8_t mode = SPI_MODE;
    uint8_t bits = SPI_BITS;
    uint32_t speed = SPI_SPEED;
    int ret;

    fd = open(SPI_DEVICE, O_RDWR);
    if (fd < 0) {
        perror("open spidev");
        return 1;
    }

    /* Set SPI mode */
    ret = ioctl(fd, SPI_IOC_WR_MODE, &mode);
    if (ret < 0) {
        perror("set SPI mode");
        close(fd);
        return 1;
    }

    /* Set bits per word */
    ret = ioctl(fd, SPI_IOC_WR_BITS_PER_WORD, &bits);
    if (ret < 0) {
        perror("set bits per word");
        close(fd);
        return 1;
    }

    /* Set max speed */
    ret = ioctl(fd, SPI_IOC_WR_MAX_SPEED_HZ, &speed);
    if (ret < 0) {
        perror("set max speed");
        close(fd);
        return 1;
    }

    printf("SPI mode: 0x%02X\n", mode);
    printf("Bits per word: %d\n", bits);
    printf("Max speed: %d Hz\n", speed);

    /* Prepare test data */
    uint8_t tx_buf[] = { 0xDE, 0xAD, 0xBE, 0xEF, 0x01, 0x02, 0x03, 0x04 };
    uint8_t rx_buf[sizeof(tx_buf)];
    memset(rx_buf, 0, sizeof(rx_buf));

    /* Build transfer structure */
    struct spi_ioc_transfer transfer = {
        .tx_buf = (unsigned long)tx_buf,
        .rx_buf = (unsigned long)rx_buf,
        .len = sizeof(tx_buf),
        .speed_hz = speed,
        .delay_usecs = 0,
        .bits_per_word = bits,
    };

    /* Perform full-duplex transfer */
    ret = ioctl(fd, SPI_IOC_MESSAGE(1), &transfer);
    if (ret < 0) {
        perror("SPI transfer");
        close(fd);
        return 1;
    }

    /* Compare TX and RX */
    printf("\nTX: ");
    for (size_t i = 0; i < sizeof(tx_buf); i++)
        printf("0x%02X ", tx_buf[i]);
    printf("\nRX: ");
    for (size_t i = 0; i < sizeof(rx_buf); i++)
        printf("0x%02X ", rx_buf[i]);
    printf("\n");

    if (memcmp(tx_buf, rx_buf, sizeof(tx_buf)) == 0)
        printf("\nLoopback test PASSED: TX matches RX.\n");
    else
        printf("\nLoopback test FAILED: TX does not match RX.\n"
               "Check that MOSI (GPIO10) is connected to MISO (GPIO9).\n");

    close(fd);
    return 0;
}
```

**Compile and run:**

```bash
gcc -o spi_loopback spi_loopback.c
sudo ./spi_loopback
```

The `struct spi_ioc_transfer` describes one full-duplex transfer: on the same clock pulses, the kernel sends `tx_buf` on MOSI and stores what arrives on MISO in `rx_buf`. The `SPI_IOC_MESSAGE(1)` ioctl runs one transfer. To run several with chip select held active, pass an array and use `SPI_IOC_MESSAGE(N)`.

## The Doorbell Monitor Application

<InArticleAd />


Now join GPIO events, the I2C sensor and the LED in one program. On each press it toggles the LED, reads the BME280, and writes one line with the time and the readings to a CSV file (a text file that a spreadsheet opens).

### Circuit Connections

| Component | Pi GPIO | Notes |
|-----------|---------|-------|
| Button (one leg) | GPIO17 | Internal pull-up enabled in software |
| Button (other leg) | GND | Press pulls GPIO17 low (falling edge) |
| LED anode (long leg) | GPIO27 | Through 330 ohm resistor |
| LED cathode (short leg) | GND | |
| BME280 SDA | GPIO2 (SDA1) | I2C data |
| BME280 SCL | GPIO3 (SCL1) | I2C clock |
| BME280 VCC | 3.3V | |
| BME280 GND | GND | |

### Complete Source Code

Most of this listing is the BME280 code you already ran. The new part is `main()` at the end: read its `while (running)` loop first. Ctrl+C sets `running` to 0, so the loop ends and `cleanup()` releases the lines and closes the files.

```c title="doorbell_monitor.c"
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <string.h>
#include <signal.h>
#include <time.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/ioctl.h>
#include <linux/i2c-dev.h>
#include <gpiod.h>

/* ---- Configuration ---- */
#define GPIO_CHIP       "/dev/gpiochip0"
#define BUTTON_LINE     17
#define LED_LINE        27
#define I2C_BUS         "/dev/i2c-1"
#define BME280_ADDR     0x76
#define LOG_FILE        "doorbell_log.csv"

/* ---- BME280 Registers ---- */
#define REG_CHIP_ID     0xD0
#define REG_CTRL_HUM    0xF2
#define REG_CTRL_MEAS   0xF4
#define REG_CONFIG       0xF5
#define REG_PRESS_MSB   0xF7
#define REG_CALIB_T1    0x88
#define REG_CALIB_H1    0xA1
#define REG_CALIB_H2    0xE1

/* ---- Globals ---- */
static volatile int running = 1;
static int i2c_fd = -1;
static struct gpiod_chip *chip = NULL;
static struct gpiod_line *button = NULL;
static struct gpiod_line *led = NULL;
static FILE *logfile = NULL;

static struct bme280_calib {
    uint16_t dig_T1;
    int16_t  dig_T2, dig_T3;
    uint16_t dig_P1;
    int16_t  dig_P2, dig_P3, dig_P4, dig_P5;
    int16_t  dig_P6, dig_P7, dig_P8, dig_P9;
    uint8_t  dig_H1, dig_H3;
    int16_t  dig_H2, dig_H4, dig_H5;
    int8_t   dig_H6;
} calib;

static int32_t t_fine;

/* ---- Signal Handler ---- */
static void sigint_handler(int sig)
{
    (void)sig;
    running = 0;
}

/* ---- I2C Helpers ---- */
static int i2c_write_byte(uint8_t reg, uint8_t value)
{
    uint8_t buf[2] = { reg, value };
    return (write(i2c_fd, buf, 2) == 2) ? 0 : -1;
}

static int i2c_read_bytes(uint8_t reg, uint8_t *buf, int len)
{
    if (write(i2c_fd, &reg, 1) != 1) return -1;
    if (read(i2c_fd, buf, len) != len) return -1;
    return 0;
}

/* ---- BME280 Calibration ---- */
static int bme280_read_calibration(void)
{
    uint8_t buf[26], hbuf[7];

    if (i2c_read_bytes(REG_CALIB_T1, buf, 26) < 0) return -1;

    calib.dig_T1 = (uint16_t)(buf[1] << 8 | buf[0]);
    calib.dig_T2 = (int16_t)(buf[3] << 8 | buf[2]);
    calib.dig_T3 = (int16_t)(buf[5] << 8 | buf[4]);
    calib.dig_P1 = (uint16_t)(buf[7] << 8 | buf[6]);
    calib.dig_P2 = (int16_t)(buf[9] << 8 | buf[8]);
    calib.dig_P3 = (int16_t)(buf[11] << 8 | buf[10]);
    calib.dig_P4 = (int16_t)(buf[13] << 8 | buf[12]);
    calib.dig_P5 = (int16_t)(buf[15] << 8 | buf[14]);
    calib.dig_P6 = (int16_t)(buf[17] << 8 | buf[16]);
    calib.dig_P7 = (int16_t)(buf[19] << 8 | buf[18]);
    calib.dig_P8 = (int16_t)(buf[21] << 8 | buf[20]);
    calib.dig_P9 = (int16_t)(buf[23] << 8 | buf[22]);

    if (i2c_read_bytes(REG_CALIB_H1, &calib.dig_H1, 1) < 0) return -1;
    if (i2c_read_bytes(REG_CALIB_H2, hbuf, 7) < 0) return -1;

    calib.dig_H2 = (int16_t)(hbuf[1] << 8 | hbuf[0]);
    calib.dig_H3 = hbuf[2];
    calib.dig_H4 = (int16_t)((hbuf[3] << 4) | (hbuf[4] & 0x0F));
    calib.dig_H5 = (int16_t)((hbuf[5] << 4) | (hbuf[4] >> 4));
    calib.dig_H6 = (int8_t)hbuf[6];

    return 0;
}

/* ---- BME280 Compensation (Bosch datasheet formulas) ---- */
static double bme280_compensate_temp(int32_t adc_T)
{
    int32_t v1, v2;
    v1 = ((((adc_T >> 3) - ((int32_t)calib.dig_T1 << 1)))
          * ((int32_t)calib.dig_T2)) >> 11;
    v2 = (((((adc_T >> 4) - ((int32_t)calib.dig_T1))
          * ((adc_T >> 4) - ((int32_t)calib.dig_T1))) >> 12)
          * ((int32_t)calib.dig_T3)) >> 14;
    t_fine = v1 + v2;
    return (t_fine * 5 + 128) / 256 / 100.0;
}

static double bme280_compensate_pres(int32_t adc_P)
{
    int64_t v1, v2, p;
    v1 = ((int64_t)t_fine) - 128000;
    v2 = v1 * v1 * (int64_t)calib.dig_P6;
    v2 = v2 + ((v1 * (int64_t)calib.dig_P5) << 17);
    v2 = v2 + (((int64_t)calib.dig_P4) << 35);
    v1 = ((v1 * v1 * (int64_t)calib.dig_P3) >> 8)
       + ((v1 * (int64_t)calib.dig_P2) << 12);
    v1 = (((((int64_t)1) << 47) + v1)) * ((int64_t)calib.dig_P1) >> 33;
    if (v1 == 0) return 0.0;
    p = 1048576 - adc_P;
    p = (((p << 31) - v2) * 3125) / v1;
    v1 = (((int64_t)calib.dig_P9) * (p >> 13) * (p >> 13)) >> 25;
    v2 = (((int64_t)calib.dig_P8) * p) >> 19;
    p = ((p + v1 + v2) >> 8) + (((int64_t)calib.dig_P7) << 4);
    return (double)p / 256.0 / 100.0;
}

static double bme280_compensate_hum(int32_t adc_H)
{
    int32_t v;
    v = t_fine - 76800;
    v = (((((adc_H << 14) - (((int32_t)calib.dig_H4) << 20)
          - (((int32_t)calib.dig_H5) * v)) + 16384) >> 15)
        * (((((((v * ((int32_t)calib.dig_H6)) >> 10)
            * (((v * ((int32_t)calib.dig_H3)) >> 11) + 32768)) >> 10)
            + 2097152) * ((int32_t)calib.dig_H2) + 8192) >> 14));
    v = v - (((((v >> 15) * (v >> 15)) >> 7) * ((int32_t)calib.dig_H1)) >> 4);
    v = (v < 0) ? 0 : v;
    v = (v > 419430400) ? 419430400 : v;
    return (double)(v >> 12) / 1024.0;
}

/* ---- BME280 Read All ---- */
static int bme280_read(double *temp, double *pres, double *hum)
{
    uint8_t data[8];
    int32_t adc_T, adc_P, adc_H;

    if (i2c_read_bytes(REG_PRESS_MSB, data, 8) < 0)
        return -1;

    adc_P = ((int32_t)data[0] << 12) | ((int32_t)data[1] << 4) | (data[2] >> 4);
    adc_T = ((int32_t)data[3] << 12) | ((int32_t)data[4] << 4) | (data[5] >> 4);
    adc_H = ((int32_t)data[6] << 8)  | (int32_t)data[7];

    *temp = bme280_compensate_temp(adc_T);
    *pres = bme280_compensate_pres(adc_P);
    *hum  = bme280_compensate_hum(adc_H);

    return 0;
}

/* ---- BME280 Init ---- */
static int bme280_init(void)
{
    uint8_t chip_id;

    i2c_fd = open(I2C_BUS, O_RDWR);
    if (i2c_fd < 0) {
        perror("open i2c");
        return -1;
    }

    if (ioctl(i2c_fd, I2C_SLAVE, BME280_ADDR) < 0) {
        perror("ioctl I2C_SLAVE");
        return -1;
    }

    if (i2c_read_bytes(REG_CHIP_ID, &chip_id, 1) < 0)
        return -1;

    if (chip_id != 0x60) {
        fprintf(stderr, "Unexpected chip ID: 0x%02X (expected 0x60)\n", chip_id);
        return -1;
    }

    if (bme280_read_calibration() < 0)
        return -1;

    /* Humidity oversampling x1 */
    i2c_write_byte(REG_CTRL_HUM, 0x01);
    /* Standby 1000ms, filter off (set before leaving sleep mode) */
    i2c_write_byte(REG_CONFIG, 0xA0);
    /* Temp x1, pressure x1, normal mode */
    i2c_write_byte(REG_CTRL_MEAS, 0x27);

    usleep(50000);
    printf("BME280 initialized (chip ID: 0x60)\n");
    return 0;
}

/* ---- GPIO Init ---- */
static int gpio_init(void)
{
    int ret;

    chip = gpiod_chip_open(GPIO_CHIP);
    if (!chip) {
        perror("gpiod_chip_open");
        return -1;
    }

    /* Configure button with pull-up, falling edge events */
    button = gpiod_chip_get_line(chip, BUTTON_LINE);
    if (!button) {
        perror("get button line");
        return -1;
    }

    struct gpiod_line_request_config btn_cfg = {
        .consumer = "doorbell-monitor",
        .request_type = GPIOD_LINE_REQUEST_EVENT_FALLING_EDGE,
        .flags = GPIOD_LINE_REQUEST_FLAG_BIAS_PULL_UP,
    };
    ret = gpiod_line_request(button, &btn_cfg, 0);
    if (ret < 0) {
        perror("request button");
        return -1;
    }

    /* Configure LED as output */
    led = gpiod_chip_get_line(chip, LED_LINE);
    if (!led) {
        perror("get led line");
        return -1;
    }
    ret = gpiod_line_request_output(led, "doorbell-monitor", 0);
    if (ret < 0) {
        perror("request led");
        return -1;
    }

    printf("GPIO initialized: button=GPIO%d, LED=GPIO%d\n",
           BUTTON_LINE, LED_LINE);
    return 0;
}

/* ---- Cleanup ---- */
static void cleanup(void)
{
    if (led) {
        gpiod_line_set_value(led, 0);
        gpiod_line_release(led);
    }
    if (button) gpiod_line_release(button);
    if (chip) gpiod_chip_close(chip);
    if (i2c_fd >= 0) close(i2c_fd);
    if (logfile) fclose(logfile);
    printf("\nCleanup complete.\n");
}

/* ---- Get Timestamp String ---- */
static void get_timestamp(char *buf, size_t len)
{
    time_t now = time(NULL);
    struct tm *tm_info = localtime(&now);
    strftime(buf, len, "%Y-%m-%d %H:%M:%S", tm_info);
}

/* ---- Main Loop ---- */
int main(void)
{
    struct gpiod_line_event event;
    struct timespec timeout = { .tv_sec = 1, .tv_nsec = 0 };
    int led_state = 0;
    int press_count = 0;
    int ret;

    signal(SIGINT, sigint_handler);

    if (gpio_init() < 0) {
        cleanup();
        return 1;
    }

    if (bme280_init() < 0) {
        cleanup();
        return 1;
    }

    /* Open log file */
    logfile = fopen(LOG_FILE, "a");
    if (!logfile) {
        perror("open log file");
        cleanup();
        return 1;
    }

    /* Write CSV header if file is empty */
    fseek(logfile, 0, SEEK_END);
    if (ftell(logfile) == 0) {
        fprintf(logfile, "timestamp,press_count,led_state,"
                         "temp_c,pressure_hpa,humidity_pct\n");
        fflush(logfile);
    }

    printf("\n--- Doorbell Monitor Running ---\n");
    printf("Press the button on GPIO%d. Ctrl+C to quit.\n\n", BUTTON_LINE);
    printf("%-20s  %-6s  %-4s  %-8s  %-10s  %-8s\n",
           "Timestamp", "Press", "LED", "Temp(C)", "Press(hPa)", "Hum(%)");

    while (running) {
        ret = gpiod_line_event_wait(button, &timeout);
        if (ret < 0) {
            if (running) perror("event_wait");
            break;
        }
        if (ret == 0) {
            /* Timeout, loop again (allows Ctrl+C check) */
            continue;
        }

        /* Read the event to clear it */
        ret = gpiod_line_event_read(button, &event);
        if (ret < 0) {
            perror("event_read");
            break;
        }

        /* Toggle LED */
        led_state = !led_state;
        gpiod_line_set_value(led, led_state);
        press_count++;

        /* Simple debounce: wait 200ms, then discard the edges that
           contact bounce queued in the kernel during that time */
        usleep(200000);
        struct timespec no_wait = { .tv_sec = 0, .tv_nsec = 0 };
        while (gpiod_line_event_wait(button, &no_wait) > 0)
            gpiod_line_event_read(button, &event);

        /* Read sensor */
        double temp, pres, hum;
        if (bme280_read(&temp, &pres, &hum) < 0) {
            fprintf(stderr, "Warning: failed to read BME280\n");
            continue;
        }

        /* Get timestamp */
        char ts[32];
        get_timestamp(ts, sizeof(ts));

        /* Print to console */
        printf("%-20s  %-6d  %-4s  %-8.2f  %-10.2f  %-8.2f\n",
               ts, press_count,
               led_state ? "ON" : "OFF",
               temp, pres, hum);

        /* Write to CSV */
        fprintf(logfile, "%s,%d,%d,%.2f,%.2f,%.2f\n",
                ts, press_count, led_state, temp, pres, hum);
        fflush(logfile);
    }

    cleanup();
    return 0;
}
```

The main loop waits in `gpiod_line_event_wait()` with a 1-second timeout. The program sleeps while it waits for a press, and once a second the timeout lets it check the `running` flag, so Ctrl+C ends it cleanly.

A mechanical button does not close once. Its contacts bounce for a few milliseconds and produce several falling edges for one press. The program handles this in two steps: it waits 200 ms with `usleep()`, then a short loop reads and discards the edges that arrived during that time. The sleep alone is not enough, because the kernel keeps every edge in a queue and would give the bounces to the next `gpiod_line_event_wait()` call.

:::tip[Instrument it]
The userspace GPIO, I2C, and SPI code in this lesson is already an instrument; point it at a real sensor instead of an LED. Wire a BME280 (temperature, humidity, pressure) on I2C or an ADXL345 on SPI, read it with the same libgpiod and spidev calls, and the Pi becomes a logger with a full Linux stack behind it. A short Python service can then [stream the readings](/education/iot-systems/) and let siliconwit.io [chart them and alert on a limit](https://siliconwit.io); when the timing has to be tight, push the front end onto an [MCU](/education/sensor-actuator-interfacing-stm32/) and let the Pi aggregate.
:::

## Exercises

<InArticleAd />


<Card title="Exercise 1: Multi-Line GPIO" icon="rocket">
Modify the blink program to control three LEDs on GPIO27, GPIO22, and GPIO23 in a sequential pattern (one lights up after the other, like a running light). Use `gpiod_chip_get_lines()` to request all three lines in a single call with a `struct gpiod_line_bulk`. Toggle them in sequence with 200 ms spacing.
</Card>

<Card title="Exercise 2: Double-Press Detection" icon="rocket">
Extend the doorbell monitor to distinguish between a single press and a double press (two presses within 500 ms). On a single press, toggle the LED normally. On a double press, flash the LED three times rapidly and log a "DOUBLE" event type in the CSV. Hint: after detecting the first falling edge, wait up to 500 ms for a second edge using `gpiod_line_event_wait()` with a short timeout.
</Card>

<Card title="Exercise 3: I2C Bus Scanner" icon="rocket">
Write a C program that replicates `i2cdetect`: scan all 112 valid I2C addresses (0x08 to 0x77) on `/dev/i2c-1` by attempting to read one byte from each address. Print a grid showing which addresses respond with an ACK. Compare your output to `i2cdetect -y 1` to verify correctness.
</Card>

<Card title="Exercise 4: SPI Sensor Integration" icon="rocket">
Connect an MCP3008 ADC to SPI0 and write a C program that reads analog channel 0 using the spidev interface. The MCP3008 protocol requires a 3-byte SPI transaction: send `0x01` (start bit), `0x80` (single-ended, channel 0), `0x00` (don't care), then the 10-bit result is in the lower bits of the last two received bytes. Display the raw ADC value (0 to 1023) and the corresponding voltage (assuming 3.3V reference).
</Card>
